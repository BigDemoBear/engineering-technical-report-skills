# 标点规范参考

## 规则如何使用

本技能按标题与序号、连接号、冒号、句内层次、并列引号和书名号组织检查。结合公开规范、科技文稿惯例和上下文判断使用各项规则。

三级标题只是默认组织建议；学校、期刊或项目的明确模板优先。数学表达、英文引文、代码、文献著录与中文正文应分别处理。具体标准要求按实际采用的条文核对。

## 公开核对入口

1. [国家标准平台：GB/T 15834—2011](https://std.samr.gov.cn/gb/search/gbDetailedCNF?id=71F772D7FE25D3A7E05397BE0A0AB82A)：核对标准身份与现行状态。修订计划不等于新版已实施。
2. [上海交通大学医学院语言文字网刊载的相关标准文本](https://www.shsmu.edu.cn/yywz/info/1026/1526.htm)：可对照连接号、并列书名号、分项结束与序次语等相关内容，例如第 4.13、4.5.3.5、A.5、A.6、B.3。网页可能存在录入或字形差异，正式判断应核对实际条文，不能据相似字形推断 Unicode 编码。

范围形式不止一种，数学符号不等同于汉语标点，并列书名号中的插入成分须单独判断，章节编号与正文列项也不是同一种格式。参考文献页码遵从实际采用的著录样式。

检查记录注明实际采用的规范、条款和位置。

## 技能联动

本技能可独立使用。与 `scientific-technical-report` 配套时，两者安装为同级目录；主技能按宿主给出的路径或相对路径读取本技能。主技能在写作流程中调用本技能完成审校。

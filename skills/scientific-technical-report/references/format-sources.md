# 默认格式的依据

`engineering-default` 结合公开科技报告资料的结构与图表惯例，选用适合日常阅读的字号和段距。目标单位或项目模板优先。

| 参考来源 | 采用内容 |
| --- | --- |
| [国家科技报告服务系统：科技报告格式模板2020](https://www.nstrs.cn/standard/detail?arid=5652)；[PDF 模板](https://www.nstrs.cn/UserDir/Documents/科技报告格式模板.pdf)；[Word 模板](https://www.nstrs.cn/UserDir/Documents/科技报告格式模板.doc) | 技术内容分章、主体结构和数字层级 |
| 广东科技学院科研处公开的 [广东省科技报告编写格式要求](https://ky.gdust.edu.cn/pics/files/附件%20广东省科技报告编写格式要求.doc) | 正文 1.5 倍行距、数字层级、图题在下、表题在上、题注居中和参考文献顺序编码 |
| [国家科技报告服务系统：GB/T 7713.3—2014 介绍](https://www.nstrs.cn/standard/detail?arid=4587) | 科技报告结构与编排的参考入口；正式条款以实际采用的标准文本为准 |

## 本技能的格式选择

- 页面采用 A4、四边 25 mm 页边距。
- 正文 12 pt，三级标题分别为 16、14、12 pt，表内及题注 10.5 pt。
- 日常报告直接进入正文；封面、目录、页眉页码和汇交要素按专用要求配置。
- 图表各自连续编号，图题在下、表题在上，表格采用三线表。
- 符号的正斜体按数学和学科含义处理。

这些参数构成本技能的默认版式。正式汇交或投稿时，按指定规范建立专用配置。机器配置见 [profile.json](../assets/profiles/engineering-default/profile.json)，样例适配见 [format-profiles.md](format-profiles.md)。

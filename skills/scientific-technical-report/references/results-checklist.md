# 结果与讨论检查清单

对每组主图/主表选择适用项执行。改编自 scientific-writing-cn，许可见根目录 THIRD_PARTY_NOTICES.md。

## 一、数字

- [ ] 给出了最重要的定量结果，而不是只写“升高/降低”；
- [ ] 关键数值与图表一致；
- [ ] 单位和小数位一致；
- [ ] 直接求解点、插值点、派生量身份明确。

## 二、现象

- [ ] 用一句话准确描述最主要趋势；
- [ ] 说明变化发生在哪里、在哪个条件下；
- [ ] 没有把局部结果写成整体结果。

## 三、原因

- [ ] 有足够证据时解释相关物理过程；证据不足时准确报告现象，不强写机制；
- [ ] 已提出的因果关系由当前数据和模型支持；
- [ ] 不是泛泛“因为协同作用/耦合效应”。

## 四、控制因素

- [ ] 数据能够区分控制因素时识别主要因素，否则说明现有证据的区分能力；
- [ ] 次要/背景因素没有与主要因素等权罗列；
- [ ] 多变量之间的角色区分清楚。

## 五、矛盾指标

- [ ] 如果两个指标趋势不同，已解释各自定义；
- [ ] 说明为什么可以同时成立；
- [ ] 判断哪个指标更接近研究目标。

## 六、科学结论

- [ ] 读者能回答“这组图如何回答报告的技术问题”；
- [ ] 结论不是“X 有影响”；
- [ ] 结论强度与证据匹配；
- [ ] 设计/运行含义如有必要，自然融入结论；
- [ ] 没有机械写“提供工程启示/理论依据”。

## 七、体系优势

- [ ] 只在数据直接支持时提出；
- [ ] 说明优势具体来自什么机制；
- [ ] 没有宣传化表达。

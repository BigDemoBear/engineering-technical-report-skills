# 成稿检查及证据回核

本页与独立标点检查共同用于成稿终检。检查实际交付版本；正式正文与独立的待补资料文件分别处理。脚本只读，支持 UTF-8 TXT/Markdown 和 DOCX，不联网、不修改文件、不更新字段。来源真实性与论断支持关系仍须打开来源审阅。

## 何时触发

- 整篇初稿形成后读取本页，按稿件实际内容执行适用检查。成稿残留检查适用于整篇交付稿；含参考文献时做引用检查；已维护关键数值台账时运行正文定位核对。
- 最终交付前核对文件版本，相关修改后复查受影响项。正文位置变化后更新 occurrences 并重跑数值检查；Word 转换后须检查最终 DOCX，不能只检 Markdown。
- 局部修订检查修改范围及关联的引用、数值和编号，不要求为短段创建整套台账。提纲、原文摘录、用户明确保留原文或不审校时服从本次范围。
- 计划报告不强求实验结果；综述不强求自有算例；没有数值或参考文献的稿件相应项记“不适用”。

## 工具入口

在技能目录下使用宿主 Python：

```text
python scripts/check_report.py <最终稿.md|最终稿.docx> --final
python scripts/audit_evidence.py <evidence.json> --final
python scripts/check_report.py <最终稿.md|最终稿.docx> --ledger <evidence.json> --final
python scripts/check_references.py <最终稿.md|最终稿.docx>
```

省略 `--final` 时允许草稿明确占位并给警告；引用检查不区分草稿/成稿，只报告当前能判定的问题。三个入口的标准输出为 UTF-8 JSON，宿主采集时按 UTF-8 解码，避免沿用 Windows 本地代码页。退出码 0 表示运行完成且无已定义错误，可以仍有警告；1 表示发现错误；2 表示输入读取/结构错误。这些状态对应各工具定义的检查范围。

### 成稿残留

明确占位采用 `[[TODO:…]]`、`【待补：…】` 等形式；成稿中未解决的明确占位是错误。普通“待定”“XX”“（略）”、强断言词和疑似空章节只提供候选。引述中的标记可能属于原文，需确认；代码、公式定界区域、路径和 URL 不按普通文字扫描。裸词或模板残留也可能漏检，必须复读全文。

逐项判断候选，不能为了消除警告删除“待定系数法”、有依据的证明、合法省略或必要的适用范围。空章节可以按任务删去或补充有依据的内容；没有材料时保留草稿状态，不填造内容。强断言要核对证据和限定条件，而不是自动弱化措辞。

### 正文关键数值

详见 [evidence.md](evidence.md) 的 occurrences。工具验证所列位置仍有原句、数值及单位，并与台账的物理量比较；不按全文字符串搜索擅自判定同名量的工况。支持 s/ms/us/μs/µs、V/kV/mV、A/kA/mA、Hz/kHz、W/kW/MW 的换算。同名自定义单位可以直接比较，其他换算需先明确口径并核对。`%` 与“百分比”可同义，`pp` 与“百分点”可同义；这两组互不等价。

显示值允许最后一位的半个单位以内舍入差异，这不是科学误差阈值。科学记数法按其显示精度处理。保留负号和原始数值，不因检查失败修改台账来迎合正文。遇到 `STALE_NUMBER_LOCATION` 先查看当前稿件；若仅位置/措辞变化，重新定位，若技术值变化，回到真实来源和计算记录。

该检查只覆盖显式列出的 occurrences。模型还须通读摘要、正文、表格、题注和结论，补齐关键重复量的所有位置；检查未列入台账的数值、峰值/有效值、一次/二次侧、相量/瞬时量、工况与误差分母。比例复算、数学推导和统计一致性按报告方法另行检查。

### 引用

顺序编码制检查可见 `[n]`、`[1,3]`、`[1–3]` 等引用及文后编号，重复引用合法。缺少条目、重复编号、无效编号区间和明确错误的标识格式会报告错误；编号顺序、未引用条目、疑似同题名/同 DOI 只给审阅候选。正文的数学区间也可能形似引用，需核对语境。章节摘录不能按完整参考文献表要求强行补号。

参考文献由独立“参考文献”/References/Bibliography 标题引入，条目按 `[n]` 开头；续行可接在该条目后，附录或同级/更高级标题结束该区域。其他著录体系、自动编号生成但未写入文本的 `[n]`、无方括号的上标、Zotero 等字段需读取真实字段/列表或查看显示，不用“未解析出条目”证明没有参考文献。

中文题名归一保留汉字。题名抽取只针对可识别的“作者. 题名[类型]”形式，重复判断需复核作者、年份、版本和原始元数据。同一 DOI 在正文出现多次是正常引用；文后多条共享 DOI 也先核查再合并。

不要求所有条目都有刊名、卷期、页码、DOI 或 ISBN。按文献类型和目标规范判断元素；文章编号不能强制改成页码。标识格式检查后，打开来源核对真实性与内容支持关系；著录规则按目标单位指定的标准版本逐项核对。

## Word 范围与语义回核

工具可读取正文、表格单元格、保存的字段显示文本、页眉页脚及脚注尾注文字，排除删除修订。`paragraph:n` 是正文 XML 顺序，不是页码；辅助部件采用 `footnotes:paragraph:n` 等定位。公式和图像用“另查”标记表示，不能据抽取结果核验其中数值。自动编号、字段是否更新、渲染顺序和版式需单独核对，转换后重新取得位置。

图表区分“未测量”“缺测”“不适用”与数值 0，不能互相代填。方法—指标—结果按报告类型复核，有计划而无结果时明确状态，不生成虚假结果。显示原始单位和有效精度；有来源/转载要求的图表保留出处。与标点审校一并检查编号、题注及正文引用，但各工具结果不相互替代。

## 结果回传

给写作主流程返回：检查的文件路径及版本标识（可用修改时间）、范围、运行项、确定问题和已修正项、仍需语义判断的候选、未检查内容。不适用项不虚报为通过。原文引用、模板规定或合法专业表达导致的候选可在独立审校记录中说明保留理由，不把清单和内部定位塞进正式正文。确定问题修正后复跑对应检查，再复读受影响句段。工具不可用时完成可执行的直接审阅，并说明未运行的机械检查。

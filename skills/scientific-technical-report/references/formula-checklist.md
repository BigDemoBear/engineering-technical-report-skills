# 公式与定义检查清单

对每个**核心公式、自定义指标、有效参数、非直观变量**选择适用项检查。改编自 scientific-writing-cn，许可见根目录 THIRD_PARTY_NOTICES.md。

## A. 公式本身

- [ ] 读者知道这条公式描述什么物理过程或数学关系；
- [ ] 核心变量已定义；
- [ ] 单位已给出或可明确推导；
- [ ] 关键项的正负号/方向有物理解释；
- [ ] 变量增大/减小的物理含义明确；
- [ ] 公式适用于当前体系的理由已说明；
- [ ] 需要耦合时，与其他方程、边界或物理场的连接已说明；
- [ ] 后续哪个结果依赖该公式已能解释；
- [ ] 不存在“公式出现了但没有进入模型”的悬空关系。

## B. 自定义指标

- [ ] 先说明“为什么需要这个指标”；
- [ ] 先说明“它衡量什么”；
- [ ] 再给符号和数学定义；
- [ ] 分子/分母、积分域、平均域或参考基线明确；
- [ ] 单位/量纲明确；
- [ ] 指标没有被误写成更高级别的实验量；
- [ ] 百分比没有被自动称为效率、准确率或其他不同定义的性能指标。

## C. 参数身份

- [ ] 实验实测；
- [ ] 文献物性；
- [ ] 模型假设；
- [ ] 有效映射参数；
- [ ] 数值设置；
- [ ] 电气报告中的一次/二次值、有效值/峰值、相量/瞬时量、线值/相值和序分量定义清楚。

以上身份没有混写。

## D. 语言

- [ ] 没有连续出现“式中 A 为…，B 为…”而缺少物理解释；
- [ ] 没有用生硬术语替代因果关系；
- [ ] 没有把方法段写成基础教材；
- [ ] 解释长度与该公式的重要性匹配。

## 通过标准

读者在不打开软件模型的情况下，应能回答：

> 这条式子算什么？为什么这样算？各项是什么意思？最后拿它做什么？
